# Aharya for iOS (SwiftUI)

A Gen Z meal planner for Indian kitchens, built along the lines of Mise: tell it how you eat
and it plans a week of meals with recipes and a grocery list. Lab reports are optional. When
the user adds them, the plan is tuned to their numbers.

## What's in it

- **Onboarding** (11 quick screens): name, age, goal, diet (veg, eggetarian, non-veg, Jain,
  vegan), cuisine, allergies, activity, height/weight (optional), household size and weekly
  budget, grocery app, what's already in the kitchen.
- **Week**: 4 meals a day for 7 days. Each meal can be pinned, swapped or ticked "ate it".
  "Shuffle the week" redraws everything that isn't pinned. Tap a meal for the recipe:
  scaled ingredients, steps, time, macros and cost per plate.
- **Haul**: the week's groceries by aisle for the whole household, with pack sizes and a
  cost estimate against the budget. Tap what you already have and it drops off.
  - **Fill my cart**: one item at a time, opens the search in Blinkit, Zepto, Instamart or
    BigBasket; you add it there and tap "added".
  - **Send to kirana**: the list as a WhatsApp message. **Share list**: the share sheet.
- **Kitchen**: tick what's in stock; the planner favours meals that use it and leaves it off
  the haul.
- **You**: profile, daily targets, optional reports, kirana number, preferences.
- **Reports (optional)**: blood report (plus urine and InBody if you have them) go to the
  Aharya API. Findings and targets come back; the week rebuilds around them (no high-GI
  meals for prediabetes, iron-rich ones for low haemoglobin, report-based calories, and so on).

Everything lives on the phone in one JSON file. There's no account. Nothing leaves the phone
unless the user sends reports.

## How it's built

- XcodeGen (`project.yml`), iOS 17, SwiftUI, `@Observable`.
- `Aharya/Resources/catalog.json`: 82 ingredients and 51 recipes, generated by
  `tools/build_catalog.py`. Edit the tables there and re-run it. Diet type, Jain suitability
  and allergens are worked out from the ingredients.
- `Model/Planner.swift`: calorie and protein targets, meal scoring (cuisine, pantry, report
  findings, budget, variety), portion scaling, budget fitting, grocery totals.
- Theme "Masala Pop" in `Theme/Theme.swift`, using the Bricolage Grotesque font (bundled).

## Run

```bash
cd ios
xcodegen generate
open Aharya.xcodeproj
```

Launch arguments: `-demo` (sample profile and week), `-reset` (wipe saved data),
`-tab week|haul|kitchen|you`. Set the `AHARYA_API_URL` environment variable to use a local
backend for reports.

## Not done yet

- Report upload is wired to the API but hasn't been tested end to end from the app.
- Grocery apps have no public add-to-cart API, so "fill my cart" opens each item's search.
- No subscriptions or paywall yet.
- Recipe calories, macros and prices are estimates; a nutritionist should review them.
