# Aharya Gen Z

A separate, Gen Z take on the Aharya app ("Masala Pop": cream, turmeric and chilli, thick
outlines, sticker cards). The original app in `../mobile` is untouched; both talk to the
same API.

## What it does

1. Onboarding: one question per screen (name, age, diet, cuisine, activity, height/weight,
   allergies, contact, consent). Saved on the phone.
2. Upload: blood report (required), urine report and InBody scan (optional), 1 to 4 weeks.
3. Reading: polls the API while it reads the reports; stops with a "see a doctor" screen
   when the API returns `needs_doctor`.
4. Home, three tabs:
   - **eats**: daily targets, day picker, meals with "ate it" ticks
   - **haul**: the week's grocery list by aisle; tap what you already have at home
   - **you**: findings, tests to add next time, house rules, kirana number
5. **Fill my cart**: walks through the haul one item at a time. Each item opens the chosen
   store's search (Blinkit, Zepto, Instamart, BigBasket); you add it there and tap "added".
   **Send to kirana** opens WhatsApp with the whole list; **share list** uses the share sheet.

"Peek a sample plan" on the welcome screen loads a bundled sample (`src/data/sample.json`,
generated by the backend's offline planner) so the app can be tried without reports.

## Why it can't fill the cart by itself

Blinkit, Zepto, Instamart and BigBasket have no public API for adding items to a user's
cart. A real one-tap cart needs a partnership; when there is one, it plugs into
`src/lib/shops.ts`.

## Run

Needs Node 20.19+ (Node 22 recommended).

```bash
npm install
npx expo start
```

Set `EXPO_PUBLIC_API_URL=http://<your-mac-ip>:8000` to use a local backend instead of
`https://aharya.fastapicloud.dev`.
